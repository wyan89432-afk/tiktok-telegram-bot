Automation project

TikTok → Telegram

A small bot that checks the public uploads of @digitalaries7 and forwards new videos and their links to a Telegram chat.

View bot runs Open source repository

Latest workflow result

The badge shows the latest GitHub Actions result. A successful run confirms the workflow completed; it does not independently confirm Telegram delivery.

How it works

01 · Check

GitHub Actions checks for recent public TikTok uploads approximately once per hour.

02 · Remember

Supabase stores video IDs and delivery state to avoid sending the same upload repeatedly.

03 · Forward

New uploads are sent to the configured Telegram chat as a video and a clickable link.

First-run behavior

The first successful run saves the videos already on the profile as a baseline. It does not forward older uploads. Later runs look for new uploads.
